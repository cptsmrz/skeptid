# SKEPTID

Multi-modal content-trust platform.
Input: email/text, image, video (audio stub).
Output: verdict + calibrated risk + verifiable evidence.

## Architecture

```
Client (SPA)
   │  HTTPS
[1] Gateway (FastAPI): validation, size limits, rate limit, auth to providers (keys server-side only)
   │
[2] Orchestrator: dispatch by modality → run provider chain → collect results
   │      config-driven: primary, fallback order, timeouts, shadow mode
   ├─ Engine: Text    ─┐
   ├─ Engine: Email   ─┤  each engine = feature/evidence logic + 3 providers
   ├─ Engine: Image   ─┤
   ├─ Engine: Video   ─┘  (frames → Image engine)
   │
[3] Providers (same interface for every engine)
   │   P1 external   : hidden API (server-side)
   │   P2 opensource : pretrained public checkpoint, unmodified
   │   P3 own        : SKEPTID forensic features + heads trained on public data
   │
[4] Fusion: combine signals into one risk score and level
   │
[5] Verdict + evidence (highlighted spans, heatmap, frame timeline)
   │
[6] Store (SQLite): analyses, per-provider results, feedback
   │
[7] Training loop: retrain → evaluate on frozen holdout → registry → gated promotion
        └──────────── updates P3 and config primary ────────────┘
```

## Three-Provider Design
Every modality engine dispatches to three independent providers:
1. **P1 (External)**: Server-side hidden API adapter.
2. **P2 (Open Source)**: Pretrained public open-source model checkpoint.
3. **P3 (Own)**: SKEPTID-trained statistical heads and forensic feature extractors.

The Orchestrator queries providers concurrently with fallback and shadow logging. Disagreements (`max(risk) - min(risk) > 0.40`) trigger explicit uncertainty reduction.

## Quick Start

### Installation
```bash
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate

pip install -e .[dev]
```

### Running Tests
```bash
make test
```

### Running the Application
```bash
make run
```

## Limitations
See [LIMITS.md](LIMITS.md) for full disclosure of platform boundaries:
- Outputs represent risk assessments with evidence, not absolute proof.
- Detection models may degrade under unseen generators, heavy compression, or adversarial manipulation.
- Multi-component fusion weights are calibrated heuristics.
- Components utilizing transfer models or pretrained encoders are explicitly documented.
